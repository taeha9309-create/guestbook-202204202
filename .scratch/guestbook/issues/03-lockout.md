# 03: 5회 실패 시 20분 잠금

**What to build:** 한 요청자가 한 글에 실패 시도를 5회 하면 그 요청자는 그 글을 20분간 수정·삭제할 수 없다. 5번째 실패 순간에는 "비밀번호가 일치하지 않습니다. 5회 틀려 20분간 잠겼습니다."를, 잠긴 동안 다시 시도하면 "비밀번호를 5회 틀려 잠겼습니다. 약 N분 후 다시 시도하세요."를 본다. 잠긴 동안에는 맞는 글 비밀번호도 거부된다. 다른 요청자와 다른 글은 영향이 없다(ADR-0001).

**Blocked by:** 02

**Status:** done

- [x] 5번째 실패 응답은 429이며 본문에 사용자용 한국어 error와 retryAfterMinutes가 있다
- [x] 잠긴 동안의 수정·삭제는 글 비밀번호가 맞아도 429로 거부되고 글은 바뀌지 않는다
- [x] 잠긴 동안에는 해시 비교를 하지 않는다
- [x] 같은 글이라도 다른 요청자는 잠기지 않고 정상적으로 수정·삭제할 수 있다
- [x] 같은 요청자라도 다른 글은 잠기지 않는다
- [x] 잠금 해제 시각이 지나면 다음 시도는 실패 시도 0부터 다시 센다

- [x] 위 동작을 API 테스트로 검증한다(20분 경과는 실제로 기다리지 않음)
