# 02: 실패 시도 세기 + 남은 시도 안내

**What to build:** 요청자가 어떤 글에 틀린 글 비밀번호로 수정 또는 삭제를 시도하면 그 (글, 요청자)의 실패 시도가 기록되고, 요청자는 그 글 아래에서 "글 비밀번호가 일치하지 않습니다. (남은 시도 N회)"를 본다. 수정 실패와 삭제 실패는 합쳐서 세고, 맞는 글 비밀번호로 성공하면 초기화된다. 요청자는 x-forwarded-for의 첫 값으로 구분한다(ADR-0001).

**Blocked by:** 01

**Status:** done

- [x] 실패 시도가 (글, 요청자) 단위로 DB에 저장되고, 첫 요청 때 저장 공간이 자동으로 준비된다
- [x] 틀린 글 비밀번호 응답은 403이며 본문에 사용자용 한국어 error와 remainingAttempts가 있다
- [x] 수정 실패와 삭제 실패가 합산되어 남은 시도가 줄어든다
- [x] 맞는 글 비밀번호로 성공하면 그 (글, 요청자)의 남은 시도가 5로 돌아간다
- [x] 다른 요청자의 실패는 내 남은 시도에 영향이 없다
- [x] 글이 삭제되면 그 글의 실패 시도 기록도 사라진다
- [x] 실패 횟수 증가는 동시 요청에도 덮어쓰이지 않는다(단일 upsert)
- [x] 화면에서 틀리면 남은 시도가 포함된 안내가 해당 글 아래에 보인다
- [x] 위 동작을 API 테스트로 검증한다(요청자는 x-forwarded-for로 흉내)
