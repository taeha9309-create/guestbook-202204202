# 04: 모던 카드 UI + 토스트

**What to build:** 방명록 화면을 깔끔한 모던 카드 스타일로 바꾼다. 은은한 그라데이션 배경, 제목 아래 개발자 이름·학번 배지, 흰 카드(둥근 모서리, 부드러운 그림자, 파스텔 포인트 색)를 쓴다. 각 글에는 작성자 이름 첫 글자 아바타, 상대 시간("3분 전", 툴팁에 정확한 KST 시각), 수정·삭제 아이콘 버튼을 둔다. 등록·수정·삭제 성공은 하단 토스트로, 입력 오류·비밀번호 불일치·잠금 안내는 해당 폼/글 아래 빨간 글씨로 보여 준다.

**Blocked by:** 03 (같은 화면을 수정하므로 충돌 방지를 위해 순서를 둠)

**Status:** ready-for-agent

- [ ] 헤더에 제목과 "김태하", "202204202" 배지가 보인다
- [ ] 아바타 색은 작성자 이름으로 정해져 같은 이름이면 항상 같은 색이다
- [ ] 작성 시각이 상대 시간으로 보이고 마우스를 올리면 정확한 한국 시간이 보인다
- [ ] 수정된 글에 "(수정됨)"이 보이고 목록 순서는 작성 시각 최신순 그대로다
- [ ] 수정·삭제가 아이콘 버튼이며 접근성 이름(aria-label)이 있다
- [ ] 등록·수정·삭제 성공 시 토스트가 몇 초간 나타났다 사라진다
- [ ] 남은 시도·잠금·입력 오류 안내가 새 스타일로 해당 위치에 보인다
- [ ] 휴대폰 너비에서 폼과 카드가 깨지지 않는다
- [ ] 외부 UI 라이브러리 없이 구현하고, 빌드와 API 테스트가 통과한다
