# 01: API 테스트 기반 만들기 (사전 정리)

**What to build:** 이미 동작하는 글 작성·조회·수정·삭제와 글 비밀번호 거부를, 실행 중인 앱의 HTTP API에 실제 요청을 보내 자동으로 검증하는 테스트를 만든다. 이후 티켓이 기존 동작을 깨뜨리지 않았는지 바로 확인할 수 있게 하는 사전 정리 작업이다. 스킬 흐름 이전에 직접 쓴 초안 문서는 spec으로 대체되었으므로 지운다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 테스트 명령 하나로 API 테스트가 실행되고, 대상 주소는 환경변수로 바꿀 수 있다(기본값: 로컬 개발 서버)
- [x] 글 작성 성공(201)과 입력 검증 실패(이름·메시지·글 비밀번호 길이, 공백만 입력 → 400)를 검증한다
- [x] 조회 결과가 작성 시각 최신순이고, 글 비밀번호 해시가 응답에 없음을 검증한다
- [x] 맞는 글 비밀번호로 수정(메시지만 바뀌고 수정됨 표시)과 삭제가 성공함을 검증한다
- [x] 틀린 글 비밀번호로 수정·삭제하면 403으로 거부되고 글이 그대로임을 검증한다
- [x] 없는 글의 수정·삭제는 404임을 검증한다
- [x] 테스트가 만든 글은 테스트가 스스로 삭제한다
- [x] 옛 초안 문서(docs의 SPEC, TICKETS)를 삭제한다
